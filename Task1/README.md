# AdScale — архитектурная диагностика и целевое видение

Task1 описывает эволюцию AdScale по шаблону Strangler Fig: сначала изолируется критичный RTB-контур, затем домены постепенно выводятся из монолита без остановки бизнеса.

## Цели

- **Через 3 месяца:** подключить новую DSP, выдержать 18 000 RPS и обеспечить P95 ответа новой DSP не более 80 ms. Требование legacy-аукциона 100 ms не является SLA нового Bidding Service.
- **Через год:** выдержать 50 000 RPS и обеспечить SLA 99,9%.
- Внутренний бюджет задержки задаётся с резервом, но становится обязательством только после нагрузочных и сквозных тестов.
