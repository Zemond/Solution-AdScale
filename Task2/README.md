# AdScale — задание 2: RTB и интеграция с DSP

## Цель

Спроектировать выделенный Bidding Service и внешний API-слой для интеграции с DSP по OpenRTB 2.x. Решение рассчитано на поэтапное внедрение: не менее 18 000 RPS через три месяца и архитектурный путь к 50 000 RPS через год при внешнем SLA DSP по времени ответа не более 80 ms.

Числа 18 000/50 000 RPS — требования к проверке нагрузочными испытаниями, а не обещание производительности. Фактическая пропускная способность, P95/P99 и запас определяются на репрезентативном профиле запросов и целевой инфраструктуре.
